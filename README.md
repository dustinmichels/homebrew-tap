# dustinmichels/homebrew-tap

Homebrew casks for:

- [Screenie](https://github.com/dustinmichels/screenie), a menu bar list of recent screenshots.
- [Resume Builder](https://github.com/dustinmichels/resume-builder), a local resume editor.

```sh
brew install --cask dustinmichels/tap/screenie
brew install --cask dustinmichels/tap/resume-builder
```

Each cask is updated automatically by its app's release script (`scripts/update-cask.sh`); don't edit its `version` or
`sha256` by hand.
