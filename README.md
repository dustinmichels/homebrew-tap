# dustinmichels/homebrew-tap

Homebrew casks for [Screenie](https://github.com/dustinmichels/screenie), a menu bar list of recent screenshots.

```sh
brew install --cask dustinmichels/tap/screenie
```

`Casks/screenie.rb` is updated automatically by Screenie's release script (`scripts/update-cask.sh`); don't edit its `version` or `sha256` by hand.
